# Bauer fork

Bauer fork. Bauer marketing starts at the `bauer-motion` skill in `bauer-automate/claude-skills`.
That skill asks a few intake questions and routes here for website promos, explainers, motion
graphics, captions, talking-head overlays, music videos and general video.

Keep this fork close to upstream. Bauer-specific guidance lives in claude-skills, not here.

Install from this fork, not from upstream: `claude plugin marketplace add bauer-automate/3P-hyperframes`, then `claude plugin install hyperframes@hyperframes`.
